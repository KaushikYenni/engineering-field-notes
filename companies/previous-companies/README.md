# Before Microsoft

## Expedia Group

I joined Expedia Group in May 2022 as a Software Development Engineer II and
moved to Software Development Engineer III in March 2025. I worked on several
parts of the insurance experience: new entry points for Hotels.com, an
orchestration service that connected shopping and post-purchase flows, and
changes around SOX audits and PCI separation.

In the later role I worked on an insurance-product rule engine, adding
operators and nested conditions so products could be filtered and
notifications scheduled more flexibly. I also remember debugging a production
SQS issue where a message returned five minutes after it had already been
processed. I think that incident was at Expedia; the
[story is here](../../stories/sqs-five-minutes.md).

## Sandvine

I was a Software Engineer at Sandvine from January 2021 to May 2022. I led the
release of a feature for detecting and diagnosing subscriber connectivity
issues in real time.

## Accolite

I was a Software Engineer at Accolite from September to December 2020. One
piece of work I remember was automating image synchronization across
distributed, multi-region server clusters.

I've also debugged production issues involving Azure Event Hubs. I didn't
build event-driven workflows from scratch; the part I remember is
troubleshooting them when they behaved unexpectedly.
