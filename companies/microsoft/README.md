# My time at Microsoft

I joined Microsoft in May 2025 as a Software Engineer 2, working on Purview
Insider Risk Management. A lot of my work sat behind the product: moving data
between systems, keeping investigation data available, and making sure noisy
activity didn't drown out signals that mattered.

The projects I want to remember are:

- [The Elasticsearch-to-Kusto migration](../../projects/elasticsearch-to-kusto-migration.md)
- [Data lifecycle management](../../projects/data-lifecycle-management.md)
- [Temporary-file noise reduction](../../projects/temporary-file-noise.md)
- [Spark signal processing](../../projects/spark-data-processing.md)

Some of my strongest memories are operational rather than feature-shaped:
watching long-running migrations, finding a way to see failures before logs
arrived, and working with the platform team when an unhealthy cluster stopped
our application from making progress. I've written those stories down in
[production stories](../../stories/README.md).
